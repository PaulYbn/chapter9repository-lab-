# Essential Commands Documentation

## pwd
Prints the current working directory path so you know where you are in the filesystem.

## ls
Lists files and directories in the current directory, helping you see what exists.

## git init
Initializes a new Git repository in the current folder by creating a `.git` directory to track history.

## git status
Displays the status of files — whether untracked, modified, staged, or committed — acting like a project radar.

## git add
Stages file changes by adding them to the index so they will be included in the next commit.

## git commit
Creates a snapshot of staged changes with a message, recording them permanently in the repository's history.
